# Таблица ручной трассировки

## 1. Число n = 472

| Итерация | n (temp) | Сумма | Количество | Условие цикла temp > 0 |
|---:|---:|---:|---:|---|
| 1 | 472 | 2 | 1 | Истина |
| 2 | 47 | 9 | 2 | Истина |
| 3 | 4 | 13 | 3 | Истина |
| Завершение | 0 | 13 | 3 | Ложь |

Результат:
- Количество цифр: 3
- Сумма цифр: 13

## 2. Число n = 0

| Итерация | n (temp) | Сумма | Количество | Условие цикла temp > 0 |
|---:|---:|---:|---:|---|
| 0 | 0 | 0 | 1 | Ложь |

Результат:
- Количество цифр: 1
- Сумма цифр: 0

## Вывод

Для подсчёта цифр и нахождения их суммы
используется цикл while. Последняя цифра
получается с помощью операции % 10,
а удаляется с помощью целочисленного деления на 10.

Для числа 0 количество цифр равно 1,
поэтому оно обрабатывается отдельно.
