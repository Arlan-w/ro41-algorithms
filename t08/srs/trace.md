# T08 — Трассировка строк в C#

## 1. Trim() и Split(';')

Дана строка:

```csharp
string s = "  Ахметов Ерлан;85 ";
```

Сначала выполняем Trim():

```csharp
s = s.Trim();
```

Результат:

```text
Ахметов Ерлан;85
```

Затем выполняем Split(';'):

```csharp
string[] parts = s.Split(';');
```

Получаем массив:

| Индекс | Содержимое | Длина |
|---|---|---|
| 0 | Ахметов Ерлан | 13 |
| 1 | 85 | 2 |

Ответ: массив содержит 2 элемента. Длины элементов — 13 и 2 символа.

## 2. Метод int.TryParse()

Дана строка:

```csharp
string line = "Иванов Пётр;70;85;X";
```

Разделяем строку:

```csharp
string[] parts = line.Split(';');
```

Проверяем каждую часть:

```csharp
for (int i = 0; i < parts.Length; i++)
{
    int.TryParse(parts[i], out int value);
}
```

Таблица трассировки:

| Индекс | Часть | TryParse | out |
|---|---|---|---|
| 0 | Иванов Пётр | false | 0 |
| 1 | 70 | true | 70 |
| 2 | 85 | true | 85 |
| 3 | X | false | 0 |

Объяснение:

- Иванов Пётр — текст, преобразование невозможно.
- 70 — число, преобразование успешно.
- 85 — число, преобразование успешно.
- X — буква, преобразование невозможно.

Ответ: если TryParseScores проверяет все части строки, он вернёт false, потому что не все части являются числами.

## 3. String и StringBuilder

Дан код:

```csharp
string s = "";

for (int i = 0; i < 4; i++)
{
    s += i;
}
```

Таблица трассировки:

| Шаг | i | Действие | Результат |
|---|---|---|---|
| 1 | 0 | s += i | "0" |
| 2 | 1 | s += i | "01" |
| 3 | 2 | s += i | "012" |
| 4 | 3 | s += i | "0123" |

Результат:

```text
0123
```

Объяснение:

Строки в C# неизменяемые (immutable). При каждой операции сложения создаётся новая строка.

Всего создаётся 4 новых строки в результате конкатенации.

Теперь рассмотрим StringBuilder:

```csharp
StringBuilder sb = new StringBuilder();

for (int i = 0; i < 4; i++)
{
    sb.Append(i);
}
```

Таблица трассировки:

| Шаг | i | Действие | Содержимое |
|---|---|---|---|
| 1 | 0 | Append(0) | "0" |
| 2 | 1 | Append(1) | "01" |
| 3 | 2 | Append(2) | "012" |
| 4 | 3 | Append(3) | "0123" |

Объяснение:

StringBuilder изменяет содержимое внутреннего буфера, поэтому не создаёт новую строку при каждом добавлении.

Ответ:
- String: создаётся 4 новые строки при сложении.
- StringBuilder: создаётся 1 объект StringBuilder. Внутренний буфер может расширяться при необходимости.
- Метод ToString() создаёт итоговую строку.

## 4. Метод ToUpper()

Дан код:

```csharp
string s = "hello";

s.ToUpper();
```

Результат работы ToUpper():

```text
HELLO
```

Но переменная s остаётся равной:

```text
hello
```

Почему?

Строки в C# неизменяемые. Метод ToUpper() возвращает новую строку с заглавными буквами, но не изменяет исходную строку.

Чтобы сохранить результат, нужно написать:

```csharp
s = s.ToUpper();
```

Теперь результат:

```text
HELLO
```

Ответ: без присваивания переменная s не изменяется, потому что результат метода ToUpper() не сохраняется.

## Общий вывод

1. Trim() удаляет пробелы в начале и конце строки.
2. Split() разделяет строку на части.
3. TryParse() проверяет возможность преобразования строки в число.
4. String создаёт новые строки при конкатенации.
5. StringBuilder позволяет изменять содержимое внутреннего буфера.
6. ToUpper() возвращает новую строку с заглавными буквами.
