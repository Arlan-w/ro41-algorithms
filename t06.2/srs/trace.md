Трассировка алгоритмов

Дан массив:

"a = {4, 1, 7, 3, 9}"

1. Циклический сдвиг влево на одну позицию

Сначала сохраняем первый элемент массива в буфер:

"temp = a[0] = 4"

Затем перемещаем остальные элементы на одну позицию влево и возвращаем сохранённое число в конец массива.

Шаг| i| Состояние массива
Начало| —| [4, 1, 7, 3, 9]
Сохранение 4| —| [4, 1, 7, 3, 9]
Перенос 1| 0| [1, 1, 7, 3, 9]
Перенос 7| 1| [1, 7, 7, 3, 9]
Перенос 3| 2| [1, 7, 3, 3, 9]
Перенос 9| 3| [1, 7, 3, 9, 9]
Возврат 4| —| [1, 7, 3, 9, 4]

Результат: [1, 7, 3, 9, 4]

2. Разворот массива на месте

Исходный массив: [4, 1, 7, 3, 9]

Меняем элементы с противоположных сторон местами.

Шаг| i| Обмен| Состояние массива
Начало| —| —| [4, 1, 7, 3, 9]
1| 0| 4 ↔ 9| [9, 1, 7, 3, 4]
2| 1| 1 ↔ 3| [9, 3, 7, 1, 4]

Результат: [9, 3, 7, 1, 4]

Выполнено 2 обмена.

Цикл выполняется только до n / 2, потому что после половины массива элементы уже поменялись местами. Средний элемент нечётного массива остаётся на месте.

3. Поиск минимума

Ошибка: начальное значение "min = 0".

Например, для массива [4, 1, 7, 3, 9] алгоритм может ошибочно оставить минимум равным 0, хотя такого элемента в массиве нет.

Исправление:

"int min = a[0];"

Затем перебираем остальные элементы массива и сравниваем их с текущим минимумом.

int min = a[0];

for (int i = 1; i < a.Length; i++)
{
    if (a[i] < min)
    {
        min = a[i];
    }
}

Результат: минимальное число — 1.

Начинать поиск с первого элемента массива правильнее, потому что он может быть как положительным, так и отрицательным.
