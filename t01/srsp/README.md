# Перевод секунд в часы, минуты и секунды

## Цель
Разработать программу для перевода общего количества секунд в часы, минуты и секунды.

## Алгоритм
1. Ввести целое неотрицательное число секунд.
2. Проверить корректность ввода.
3. Вычислить часы: H = N / 3600.
4. Вычислить минуты: M = (N % 3600) / 60.
5. Вычислить секунды: S = N % 60.
6. Вывести результат.

## Результаты тестирования

| Ввод | Часы | Минуты | Секунды |
|---:|---:|---:|---:|
| 3725 | 1 | 2 | 5 |
| 59 | 0 | 0 | 59 |
| 86399 | 23 | 59 | 59 |
| 0 | 0 | 0 | 0 |

## Проверка ошибок
Ввод abc: сообщение об ошибке.
Ввод -5: сообщение об ошибке.

## Язык программирования
C#

## Вывод
Программа корректно переводит секунды в часы, минуты и секунды и обрабатывает некорректный ввод.
