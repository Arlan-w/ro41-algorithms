# Трассировка F(4)

Функция: `static int F(int n) { if (n <= 1) return 1; return n * F(n - 1); }`

## 1. Базовый случай и шаг рекурсии
- Базовый случай: `n <= 1`, возвращается 1.
- Шаг рекурсии: `n * F(n - 1)`.

## 2. Трассировка F(4)

| Вызов | Глубина | Возвращает |
|---|---|---|
| F(4) | 0 | 4 * F(3) = 24 |
| F(3) | 1 | 3 * F(2) = 6 |
| F(2) | 2 | 2 * F(1) = 2 |
| F(1) | 3 | 1 (базовый случай) |

Вызовы идут вниз: F(4) → F(3) → F(2) → F(1).
Значения возвращаются вверх: 1 → 2 → 6 → 24.

## 3. F(-1) при условии `n == 1`
Условие `n == 1` никогда не выполнится для -1: n только уменьшается
(-1, -2, -3, ...). Базовый случай не достигается, рекурсия бесконечная.
Каждый вызов занимает место в стеке вызовов, он переполняется, и
программа падает с `StackOverflowException`.
