# T10 — Сортировки и бинарный поиск

## 1. Сортировка выбором (Selection Sort)

Дан массив:

```csharp
int[] a = { 5, 2, 9, 1, 7 };
```

Алгоритм ищет минимальный элемент и меняет его местами с первым элементом неотсортированной части массива.

### Таблица трассировки

| Проход i | Индекс минимума | Массив после обмена | Сравнения |
|---|---|---|---|
| 0 | 3 | [1, 2, 9, 5, 7] | 4 |
| 1 | 1 | [1, 2, 9, 5, 7] | 3 |
| 2 | 3 | [1, 2, 5, 9, 7] | 2 |
| 3 | 4 | [1, 2, 5, 7, 9] | 1 |

### Подсчёт сравнений

4 + 3 + 2 + 1 = 10

**Ответ:**

- Итоговый массив: [1, 2, 5, 7, 9].
- Общее количество сравнений: 10.

## 2. Сортировка вставками (Insertion Sort)

Дан массив:

```csharp
int[] a = { 4, 3, 2, 1 };
```

Алгоритм берёт элемент и вставляет его на правильное место среди предыдущих элементов.

### Таблица трассировки

| i | key | Число сдвигов | Массив после вставки |
|---|---|---|---|
| 1 | 3 | 1 | [3, 4, 2, 1] |
| 2 | 2 | 2 | [2, 3, 4, 1] |
| 3 | 1 | 3 | [1, 2, 3, 4] |

### Подсчёт сдвигов

1 + 2 + 3 = 6

**Ответ:**

Всего выполнено 6 сдвигов.

### Сравнения на отсортированном массиве

Дан массив:

```csharp
int[] a = { 1, 2, 3, 4 };
```

| i | key | Сравнение | Сдвиги |
|---|---|---|---|
| 1 | 2 | 1 < 2 | 0 |
| 2 | 3 | 2 < 3 | 0 |
| 3 | 4 | 3 < 4 | 0 |

**Ответ:**

- Сравнений: 3.
- Сдвигов: 0.

## 3. Бинарный поиск (Binary Search)

Дан отсортированный массив:

```csharp
int[] a = { 1, 3, 5, 7, 9, 11, 13 };
```

Бинарный поиск делит массив пополам и проверяет средний элемент.

### Часть 1. Поиск x = 7

Начальные значения:

```text
lo = 0
hi = 6
```

Формула:

```text
mid = (lo + hi) / 2
```

### Таблица трассировки

| Шаг | lo | hi | mid | a[mid] | Решение |
|---|---|---|---|---|---|
| 1 | 0 | 6 | 3 | 7 | Найдено |

**Ответ:**

Число 7 найдено по индексу 3.

### Часть 2. Поиск x = 6

Начальные значения:

```text
lo = 0
hi = 6
```

### Таблица трассировки

| Шаг | lo | hi | mid | a[mid] | Решение |
|---|---|---|---|---|---|
| 1 | 0 | 6 | 3 | 7 | hi = 2 |
| 2 | 0 | 2 | 1 | 3 | lo = 2 |
| 3 | 2 | 2 | 2 | 5 | lo = 3 |

После третьего шага:

```text
lo = 3
hi = 2
```

Условие lo <= hi больше не выполняется.

**Ответ:**

Число 6 не найдено в массиве.

### LowerBound(6)

LowerBound возвращает индекс первого элемента, который больше или равен искомому числу.

Массив:

```text
[1, 3, 5, 7, 9, 11, 13]
```

Первое число, которое больше или равно 6, — это 7.

Оно находится по индексу 3.

**Ответ:**

```text
LowerBound(6) = 3
```

## Общий вывод

1. Сортировка выбором выполнила 10 сравнений.
2. Сортировка вставками выполнила 6 сдвигов.
3. На отсортированном массиве из 4 элементов выполнено 3 сравнения и 0 сдвигов.
4. Бинарный поиск нашёл число 7 по индексу 3.
5. Число 6 не найдено.
6. LowerBound(6) вернул индекс 3
